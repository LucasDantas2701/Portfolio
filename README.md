# Portfólio — Lucas Dantas

Site pessoal com meus projetos, experiência e contato. Feito com React, TypeScript, Vite e Tailwind CSS.

## Rodando localmente

```bash
npm install
npm run dev
```

## Atualizando o conteúdo

Todos os textos e dados (perfil, habilidades, projetos, linha do tempo, contato) ficam em `src/data/profile.ts`. Os componentes em `src/components/` só cuidam do visual.
